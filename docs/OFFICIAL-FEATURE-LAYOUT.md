# Official Feature layout

New Original Features inherit the official layout from the `Original Feature` eyebrow; `presentation: "official"` may also select it explicitly. The layout places the title, author, publication date, and Feature audio control on the left; complete uncropped artwork sits on the right. The article follows a divider in a centered reading column, with source links preserved at the end. On narrow screens, the hero stacks and the artwork keeps its intrinsic ratio. Explicit launch and analysis presentations, including existing historical layouts, keep their current treatment.

`FeatureAudioPlayer` is shared by the Feature page and homepage card. It shows measured media time only after audio metadata loads, allows seeking when duration is available, handles interrupted `play()` calls without latching an error, permits retry after a real failure, and pauses other audio elements when any player starts. The homepage `HomePulseHero` listens for native `pause` events and updates its visible play state when the coordinator pauses it. The verified Teaching Superpower master measures 402.68 seconds and displays as 6:43; live playback controls use the media element's loaded duration. Do not add an estimated runtime or a recording-ready claim.

On the homepage, the Original Feature remains after newsletter signup and before This Week's Stories. Keep the artwork, approved title and excerpt, byline, date, Feature listen control, and Read action. Existing historical Features keep their layout and prose unless explicitly assigned the official presentation.
