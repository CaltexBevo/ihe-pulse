Canvas Quiz Builder
Quiz Builder v7.5 · QTI 2.1 Export for Canvas New Quizzes
This tool lets you quickly create quiz question packages that import directly into Canvas New Quizzes. Paste your questions into the tabs below — each tab handles a different question type — then export a single QTI 2.1 ZIP file ready for Canvas import. No software to install, no account needed. Everything runs in your browser.
📖 Supported Question Types
  • Multiple Choice — single correct answer
  • True / False — binary choice
  • Multiple Answer — select all that apply
  • Fill in the Blank — typed response with accepted answers
  • Essay — open response, human graded
🚀 How to Use This Tool
  1. Fill in your Quiz Settings below (title, chapter number, etc.).
  2. Click a question type tab (Multiple Choice, True/False, etc.).
  3. Paste your questions in the format shown, then click the Add button. Your pasted text stays in the box so you can reference or re-add it.
  4. Repeat for other question types as needed — they all combine into one quiz.
  5. Set points per question type: Each tab has a PTS EACH field next to the Add button. Set this before clicking Add to assign points to that batch. You can set different values for each type (e.g. 2 pts for Multiple Choice, 5 pts for Essay). You can also adjust points for individual questions in the Review All tab.
  6. Formatting help: If any questions can't be parsed, you'll see specific suggestions explaining what went wrong — such as a missing (correct) marker, too few answer choices, or an answer line that doesn't match the expected format. Follow the hints to fix your text and re-add.
  7. Use the Review All tab to check everything. You can edit question text, answers, correct answers, point values, and add or remove answer choices — all inline. Delete any question with the ✕ button.
  8. Click Export QTI ZIP to download the file.
📥 How to Import into Canvas
  1. In your Canvas course, go to Quizzes and click + Quiz.
  2. Select New Quiz and click Submit.
  3. Title your quiz and click Build.
  4. Click the ⋯ Options icon (top-right) → Import Content.
  5. Drag and drop the downloaded .zip file, then click Import.
  6. Your questions appear in the quiz — ready to publish!

You can also import into Item Banks: go to Item Banks → create or select a bank → Import → upload the ZIP.

📋 Quiz Settings

PTS EACH
Format: Number each question (1. or 1)). List choices as a) b) c) d). Mark the single correct answer with (correct) after the text, or prefix the line with *. Separate questions with a blank line.
PTS EACH
Format: Number each question. On the next line, write True or False — this is the correct answer. Separate questions with a blank line. You can also use the lettered format: a) True (correct) / b) False.
PTS EACH
Format: Same as Multiple Choice, but mark two or more correct answers with (correct) or *. Separate questions with a blank line.
PTS EACH
Format: Number each question. List each acceptable answer on its own line starting with * (asterisk + space). You can list multiple acceptable spellings. Separate questions with a blank line.
PTS EACH
Format: Number each question — just the prompt text, no answers needed. Separate questions with a blank line. Each becomes an open-response (human-graded) item in Canvas.
